# ESP Mod

Enhance your Minecraft experience with ESP functionality

## Features

- Highlight specific blocks within a customizable range
- User-friendly GUI for easy configuration

## Requirements

- Minecraft 1.21.11
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/esp-mod/releases)
2. Place the mod in your `mods` folder
3. Launch Minecraft with Fabric

## Usage

1. Press the right shift key to open the ESP Mod GUI
2. Click on the ESP button to select a block to highlight
3. Adjust the range using the range button

## Configuration

The mod does not require any additional configuration files. All settings can be adjusted through the in-game GUI.
